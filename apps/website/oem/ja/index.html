OriginMind AI OS™は、実環境で稼働するロボット向けのRobot Agent OSです。明確な製品ロードマップを持つロボットメーカーを対象に、先行OEMパートナー企業を5社限定で募集します。初期技術評価後、対象機種、インターフェース設計、システム統合、現場検証を共同で進めます。要件整理、インターフェース設計、初期実機検証は現在も実施可能です。プロジェクト開始時には、Foundation版は20ライセンス以上、Advanced版は10ライセンス以上の初回一括購入が必要です。

リリース計画

段階的な開発と検証を経て、順次リリースします

2026年末までは、要件整理、インターフェース設計、試作、段階的なテストを中心に進めます。その後、Foundation版、Advanced版の順にリリースします。

  1. 2026年8月〜12月
    CO-DEVELOPMENT

    お申し込み・初期評価・共同開発

    ロボット本体の仕様と対象ユースケースを確認し、インターフェース仕様、技術方針、段階的なデモンストレーション、試験準備を進めます。

  2. 2027年1月
    FOUNDATION RELEASE

    Foundation版 リリース予定

    移動ロボット、点検ロボット、AGV向けに、ナビゲーション、自己位置推定、環境認識、SLAM、OriginMind AI OS™との統合機能をご提供します。

  3. 2027年2月〜5月
    MANIPULATION BETA

    Advanced版のリリース前検証

    Foundation版を基盤として、ロボットアーム制御、モバイルマニピュレーション、双腕協調を段階的に実機検証します。

  4. 2027年6月
    ADVANCED RELEASE

    Advanced版 リリース予定

    初期技術評価を通過し、正式なプロジェクト契約を締結したパートナー企業は、合意したスケジュールに基づき、統合、導入、試験、検収へ進みます。
