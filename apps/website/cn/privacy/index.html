隐私说明

了解中文官网、英文官网访问统计与合作咨询的信息处理方式。

最后更新：2026-10-17

本说明适用于 OriginMind 中文官网（omindos.cn），并说明英文官网（omindos.ai/en/）访问统计与合作咨询的信息处理。OriginMind 网站由深圳源灵智能科技有限公司运营。如对本说明或此前提交的合作资料有疑问，请联系 sales@omindos.ai。

阅读要点

  • 官网统计的是页面访问次数，不代表去重访客人数或真实在线人数。
  • 联系页的需求摘要在当前页面生成，不会自动提交；发送邮件前由您确认。
  • 历史合作资料如需查询、更正或删除，请查看留存与请求说明，或通过下方邮箱联系我们。

一、中文官网与相关服务

中文官网由腾讯云服务器提供页面和媒体资源，不设用户注册表单。启用 JavaScript 的官网页面首次可见时，会向本站同源接口发送一次匿名页面访问计数。新口径跳过浏览器明确标记的自动化运行、预渲染和预取，并在计数接口中排除已识别的常见爬虫与自动化工具。这些规则只影响计数，不限制正常用户或搜索引擎读取网页；规则不能识别所有自动化访问，也不证明一次访问来自真人。统计代表经过上述规则过滤的页面访问次数，不代表去重访客人数或真实在线人数。中文官网不向英文官网或旧站的统计数据库发送新的浏览记录。服务器在提供服务、排查故障及防范异常访问时，可能记录 IP 地址、请求路径、访问时间和浏览器信息等必要的技术日志。

本站访问统计在腾讯云保存累计次数和按分钟汇总的近期次数，不保存原始 IP 地址、账户、Cookie、浏览器指纹或唯一访客 ID。防止异常重复计数时，连接地址只用于短期内存限流，不写入统计数据库。分钟级汇总保留约两天，累计次数目前不设自动删除期限。

自 2026-10-17 新口径启用起，中文官网的累计与近 24 小时页面访问单独统计。此前中文官网已采集的页面访问保留为未过滤历史，不能准确追溯其中的机器人比例。另行保留的 1,109 次旧 Pages 站点历史快照来自 originmind.pages.dev/api/visits，并非中文官网访客数据；旧快照的地区分布也不能视为中文官网的访问地区。两类历史均不并入新口径累计，不用于计算真实人数或在线人数。中文新增页面访问暂不定位国家或地区。

OA 工作台、OmindOS Cloud、课程、竞技场及 AI 助手属于独立服务。其用户上线与登录统计需要各自的会话或心跳证据，不能由官网页面访问推算。进入这些服务后，登录、学习记录、任务或对话等信息按相应服务的功能处理；本页对静态官网的说明不代表这些服务不处理账户或业务数据。

二、英文官网访问统计

英文官网通过其同源接口独立统计页面访问，并可使用托管平台提供的国家或地区代码。其历史累计可能包含自动化访问，无法据此确定去重访客人数或真实在线人数；Cloudflare 的自动化 HTTP 请求比例也不等于网站页面访问计数中的机器人比例。英文官网的新旧统计口径以英文官网说明和接口元数据为准，不与中文官网合并。

网站应用不会把原始 IP 地址、浏览器指纹、广告标识符或唯一访客 ID 写入访问统计数据库。数据库保存累计页面访问量、按国家或地区累计的访问量，以及按分钟和国家或地区汇总的近期访问量。新的访问记录写入时，系统会清理两天以前的分钟级汇总；累计总数和国家或地区累计目前未设置固定的自动删除期限。

旧版语言页面会在浏览器本地存储中以 originmind.language 保存所选语言，并可能设置名为 originmind_language、最长保存一年的功能性 Cookie。本地存储没有固定到期时间，会保留到您清除该网站的浏览器数据为止；二者均不用于访问统计或广告。

三、合作咨询

当前中文官网通过电子邮件接收项目咨询。联系页的需求摘要工具仅在当前页面整理您输入的场景、任务和联系方式，不会自动提交，也不写入网站的本地持久存储。复制内容会将摘要写入设备剪贴板；点击邮件入口会把摘要带入您的邮件应用，由您确认发送。发送后，我们会使用您提供的联系方式和项目资料进行沟通。

请勿在咨询信息中填写密码、身份证件号码、财务账户资料，或与项目无关的敏感信息。

四、处理目的

我们使用合作咨询信息评估机器人平台与项目需求，并安排后续沟通；使用必要的技术信息维护网站运行、防范异常访问和生成汇总统计。

五、存储与访问

此前通过网站提交的合作资料保存在网站数据库中，仅供授权管理员评估需求和联系跟进，不通过公开列表接口提供。中文官网的匿名访问计数独立保存在腾讯云，与合作资料分别存储。

六、留存与您的请求

历史合作资料目前未设置固定的自动删除期限。如需查询、更正或删除此前提交的合作资料，请发送邮件至 sales@omindos.ai。

七、服务提供方

中文官网的页面与媒体托管使用腾讯云；英文官网及其访问统计使用 Cloudflare 服务。相关服务在提供、保护和维护网站时可能处理必要的技术请求信息。如果您选择通过电子邮件联系我们，邮件服务提供方也会处理您发送的邮件内容。

八、联系我们

有关本说明、访问统计或合作咨询信息的问题，请联系：sales@omindos.ai。
