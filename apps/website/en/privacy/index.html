ORIGINMIND / DATA & PRIVACY

Privacy Notice

How the Chinese and English websites, project enquiries and historical OEM applications handle information.

Last updated: 2026-10-14

This notice covers the Chinese website (omindos.cn), the English website (omindos.ai/en/) and information submitted through the former Founding OEM Partner Program form. OriginMind is operated by 深圳源灵智能科技有限公司. For questions about this notice or a submitted application, contact sales@omindos.ai.

1. Chinese website and related services

The Chinese website serves static pages and media from Tencent Cloud. It has no user registration form and does not send page-view records to the English website statistics database. Server operations may record technical logs such as IP addresses, request paths, access times and browser information to deliver the service, diagnose faults and prevent abnormal access.

OA, OmindOS Cloud, courses, the robot arena and the AI assistant operate as separate services. Their account, learning, task and conversation data are handled according to their respective functions. This notice about the static website does not mean those services process no account or business data.

2. English website usage statistics

When a page in the English website loads, it sends one record to a same-origin statistics endpoint. The website application uses the country or region code supplied by the hosting platform to count page loads, recent activity, and country- or region-level totals. These figures represent page loads, not unique visitors.

The website application does not write raw IP addresses, browser fingerprints, advertising identifiers, or unique visitor IDs to the statistics database. The database stores the cumulative page-load count, cumulative counts by country or region, and recent counts grouped by minute and country or region. When a new visit is recorded, minute-level aggregates older than two days are removed. The cumulative total and cumulative country or region counts do not currently have a fixed automatic deletion period.

Legacy language pages store the selected language in browser local storage under originmind.language and may also set a functional cookie named originmind_language for up to one year. Local storage has no fixed expiry and remains until you clear this site’s browser data. Neither mechanism is used for usage statistics or advertising.

3. Project enquiries and historical OEM applications

The Chinese website currently receives project enquiries by email. Its contact-page summary tool only arranges the information you enter in the current page; it does not automatically submit it or save it in persistent browser storage. Copying places the summary on your device clipboard. Opening the email link transfers it to your email application, where you choose whether to send it. After sending, we use the contact details and project information for follow-up. The following paragraphs continue to apply to applications submitted through the former OEM form.

For applications submitted through the former Founding OEM form, we process the company name, contact name and work email you provide, together with any phone, WhatsApp or WeChat contact details you choose to provide. We also process the robot type or model, operating system and interfaces, preferred start date, expected deployment quantity, current and target capabilities, test-unit and interface-documentation status, selected program track, and any additional project notes.

The system also stores the form language, submission time, receipt number, submission identifier, the version of this notice accepted with the application, and a hash used to check content integrity. To limit repeated or abnormal submissions, the website processes the connection IP address to create a date-derived source hash. The raw IP address is not written to the OEM application table, but the derived source hash is stored with the application record.

Do not include passwords, government identification numbers, financial account details, or sensitive information unrelated to the application.

4. How we use the information

We use this information to assess the robot platform and project requirements, contact the applicant, arrange follow-up, issue and match receipts, support safe retries, prevent abuse, and maintain aggregate website operating statistics. Submitting an application does not confirm a partner slot, create a payment commitment, or start a project.

5. Storage and access

OEM applications are stored in the website database and are available through a restricted internal administration system to authorized administrators for application review and follow-up. Application contents are not available through a public listing endpoint. English website statistics and historical OEM applications are stored in separate tables within the website database, independently of Chinese static-page hosting. Historical consent records retain the notice version accepted when the application was submitted.

6. Retention and your requests

OEM application records do not currently have a fixed automatic deletion period. Application information is used for evaluation, follow-up and receipt matching. To ask what application information we hold, or to request correction or deletion of a submitted application, email sales@omindos.ai. Include the receipt number when available so that we can identify the record.

7. Service providers

The Chinese website uses Tencent Cloud for pages and media. The English website, its statistics database and the historical OEM application system use Cloudflare services for hosting, database storage and request processing. Those services may process technical request information as needed to deliver, protect and maintain the website. If you choose to contact us by email, the email service provider will also process the contents of your message.

8. Contact

For questions about this notice, website usage statistics or OEM application information, contact sales@omindos.ai.
