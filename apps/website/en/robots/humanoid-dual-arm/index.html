Core capabilities

The system brings visual perception, task planning and motion control into one verifiable workflow for two arms working on the same task.

Dual-arm task allocation

Assign actions to the left and right arms according to the object, workspace and process sequence, then coordinate execution timing.

Visual localisation and grasp planning

Use RGB-D sensing for scene and object poses, supporting recognition, 6D pose estimation and grasp-pose planning.

Coordinated avoidance and compliant control

Plan smooth, collision-free dual-arm paths and apply compliant collaborative control to assembly tasks.

Application directions

For precise and flexible tasks that require two robot arms to work together.

Flexible precision assembly

Locate, grasp, regrasp and assemble connectors, 3C components and other small parts.

Complex object handling

Use handovers and regrasps to adjust object pose before the next process or assembly step.

Embodied-AI research

Provide hardware interfaces for task planning, reinforcement learning, imitation learning and humanoid-manipulation validation.
