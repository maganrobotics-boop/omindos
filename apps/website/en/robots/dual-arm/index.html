From perception to coordinated manipulation

Connect object recognition, grasp planning and dual-arm control for manipulation research and task validation.

3D perception

Use RGB-D sensing and point clouds for object segmentation, recognition and 6D pose estimation, providing inputs for grasp planning.

Grasp planning

Select grasp poses based on object geometry, gripper design and the available workspace, connecting perception to manipulation.

Regrasping and handovers

Transfer objects between the arms and adjust their orientation to prepare for assembly, pouring or other manipulation tasks.

Motion planning and collision checking

Plan movements using robot kinematics and scene constraints, coordinating both arms and checking for collisions.

Digital twin integration

Observe robot states and validate movements in a virtual model, then link the model with physical motion and execution.

Control and software development

Access joint states, motion control and forward/inverse kinematics to support reinforcement-learning experiments and higher-level algorithm development.

Fixed-platform reference configuration

These reference specifications describe the fixed experimental platform with two collaborative robot arms. The tabletop service prototype has a separate configuration.

Specifications refer to the configuration in the product manual. Component selection and delivery scope are confirmed for each project. Arm repeatability does not represent the assembly accuracy of the complete platform.
