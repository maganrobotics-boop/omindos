# OriginMind 矿物绿品牌试版

沿用参考首页的全屏视频、大幅图片与简短英文叙事，使用 OriginMind 自有品牌与素材。石墨灰、矿物绿、白色构成新配色，品牌标志沿用官网原始图标。

## 构建与范围

- 构建：`node design-studies/mujin-light-blue/build.mjs`
- 检查：`python3 design-studies/mujin-light-blue/validate.py`
- 输出：`apps/website/design-study/`，独立入口 `/design-study/`。
- 10 个品牌页面：首页、移动能力、现场验证、仓库、金属矿井、任务级系统、合作方式、关于我们、机器人产品与报价、联系。
- 83 个旧试版地址重定向至相应品牌页面；参考站原始数据文件保留在源码中，不参与品牌页面渲染。
- 正式三语网站、OEM 表单、后端、统计和部署配置不变。仅更新 `website-mujin-light-blue-review` 分支，不合并到 main。

## 内容与素材

首页恢复参考站的“视频开场 → 品牌与产品 → 系统 → 移动能力 → 合作 → 现场案例”顺序。移除编号、流程框和密集文字卡片，以大图配短标题和一两句介绍；详细说明仍在内页。仅保留参考站六个词的首屏标题“Advancing robotics with physical AI”，其余英文围绕 OriginMind 已有业务简写，不转用参考站的产品、新闻、客户及商业数据。任务级系统协调能力调用、执行步骤与反馈；面向硬件厂商提供 OS，面向场景集成商提供任务方案。

- 用户确认矿井属于金属矿；所有品牌页面使用 metal mine。
- 用户提供的矿井照片 `1000088956.jpg` 转换为 WebP，用于现场环境展示，不识别照片人物。
- 金属矿井四足场景主图采用用户最新提供的 `1000089013.jpg`（更新双雷达外观），替换之前的 `1000089006.jpg`。位置在金属矿井详情页标题下方，标为“Application concept rendering · Engineering prototype in development”。保留完整画幅；原矿井实拍和履带实机视频仍在后续内容中展示。
- 用户最终选定五张实验室机器人效果图，均转换为 WebP、保留完整画幅，统一标为“Laboratory robot rendering”。四足另外标注“Engineering prototype in development”。旧四足图和系统集成 AI 示意图不再用于页面展示。

## 版式与验收

首页恢复参考站的图文对照和左对齐短文案：全屏视频、宽幅产品图、系统图片与折叠说明、两列能力/合作/案例大图。桌面页眉保留品牌与菜单按钮，手机按顺序单列展示。首页样式独立于详情页，详情页原有布局保留。正文 17–22px、说明文字至少 14px；产品效果图保留完整比例。六段实机视频仍默认折叠，背景视频直接引用远端。

验证覆盖 94 个 HTML 文件的结构、标题、链接、锚点、品牌和媒体来源，JavaScript 语法，以及官网现有回归测试。本地浏览器预览受环境限制，桌面和手机视觉及真实播放仍待验收。GitHub 审核版更新不等于正式网站或临时预览部署。
